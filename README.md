# DermaCand

**Guía de consulta rápida en Dermatología** — PWA clínica de bolsillo (un solo archivo).

- App: [`DermaCand_app.html`](DermaCand_app.html)
- Asistente virtual: **Mel** (un melanocito).
- Tema clínico teal · escalas/scores dermatológicos · pautas de tratamiento · transcriptor de analíticas · listín telefónico · visor de PDF.

## Autoría
- **Busnego Barreto, M.T.** — diseño, desarrollo, estructura y arquitectura de la aplicación.
- **García Silvera, D.** — contenidos clínicos de dermatología.

## Desarrollo local
Servir en `http://localhost:5180/`:

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1 -Port 5180
```

> Repositorio privado. Apoyo a la decisión clínica; no sustituye el juicio del facultativo ni los protocolos del centro.
